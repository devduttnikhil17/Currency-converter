# Currency Converter

A simple and responsive currency converter web application built using HTML, CSS, and JavaScript. The application allows users to convert currencies in real time using an external exchange rate API.

## Features

- Convert between different world currencies
- Real-time exchange rates
- Country flags displayed with currency selection
- Clean and responsive user interface
- Mobile-friendly layout

## Technologies Used

- HTML
- CSS
- JavaScript
- Exchange Rate API

## How It Works

1. Enter the amount you want to convert.
2. Select the currency you want to convert from.
3. Select the currency you want to convert to.
4. Click the "Get Exchange Rate" button.
5. The converted amount will be displayed instantly.
